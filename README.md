# Sistema de gerenciamento de uma oficina mecanica 

Utilizando as seguintes linguagens: 
- JavaScript
- TypeScript
- Mysql

  Projeto focado em uma API rest com CRUD para uma oficina, pensando na criptografia do cpf e senha de de usuario.
  Modelei o banco de dados do zero com o objetivo de estudo e aprendizado desde a base. Assim
  podendo executar um backend bom e eficaz com o banco de dados bem estruturado.

  # PROJETO PARA FINS EDUCATIVOS
  
PARA UTILIZAR --> baixe o npm node.js
